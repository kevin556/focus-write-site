FOCUS Write — Éditeur Markdown pour macOS

Questions fréquentes

Quels formats de fichiers sont pris en charge ?
FOCUS Write ouvre et enregistre les fichiers Markdown (.md, .markdown) et texte brut (.txt).

Où sont stockés mes documents ?
Vos documents restent exactement là où vous les enregistrez sur votre Mac. FOCUS Write ne déplace ni ne copie vos fichiers.

L'application fonctionne-t-elle hors ligne ?
Oui, entièrement. FOCUS Write ne nécessite aucune connexion internet.

Comment exporter en PDF ou HTML ?
Menu Fichier → Exporter en PDF… ou Exporter en HTML…

Quelle version de macOS est requise ?
macOS 14.0 (Sonoma) ou ultérieur.

Comment changer le thème ou la police ?
Menu FOCUS Write → Réglages (⌘,) puis onglet Apparence.
