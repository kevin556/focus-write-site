Politique de confidentialité

FOCUS Write — Éditeur Markdown pour macOS

Aucune donnée collectée

FOCUS Write est une application native macOS qui fonctionne entièrement hors ligne. Elle ne collecte, ne transmet et ne stocke aucune donnée personnelle.

Ce que FOCUS Write ne fait pas

  • Aucun compte utilisateur ni inscription
  • Aucune analyse (analytics) ni tracking
  • Aucun cookie ni identifiant publicitaire
  • Aucune connexion réseau sortante
  • Aucune télémétrie ni collecte de crash

Stockage local

Vos documents Markdown sont enregistrés exclusivement sur votre appareil, à l'emplacement que vous choisissez via le dialogue système standard de macOS (NSOpenPanel / NSSavePanel).

Les préférences de l'éditeur (thème, taille de police, mode d'écriture) sont stockées localement dans UserDefaults, sur votre Mac uniquement.

App Sandbox

FOCUS Write fonctionne dans le bac à sable macOS (App Sandbox). L'application accède uniquement aux fichiers que vous ouvrez ou créez explicitement.

Enfants

FOCUS Write ne collectant aucune donnée, elle est conforme aux réglementations relatives à la protection des données des enfants (COPPA, RGPD).
